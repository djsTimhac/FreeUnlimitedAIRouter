Why it exists

Free tiers are fragile.
Your app shouldn't be.

Every free provider has a ceiling — tokens per minute, requests per day, a key that quietly dies. The router treats all of that as normal weather and routes around it.

Ordered fallback

One model name resolves to a queue of providers. A 429, 401, a 5xx, a timeout or even a broken 200 body moves the request to the next one — before a single byte reaches your client.

Key rotation

Comma-separate as many keys as you own. The router spreads load over the least recently used one and quarantines the exhausted key instead of hammering it.

Cool-downs that respect the API

Honours Retry-After and x-ratelimit-reset-*, otherwise backs off exponentially up to 15 minutes.

Streaming, end to end

Server-sent events pass straight through. Fallback happens before the first token, never in the middle of an answer.

Anthropic, translated

Claude speaks a different dialect. The router converts requests, responses, tool calls and streams in both directions — so Claude is just another candidate behind smart.

A dashboard, not a black box

Provider health, a bar per key, latency, token counts, which aliases are actually servable right now — plus a streaming playground at /.

How it works

Three lines from “it's down”
to “it just works”.

01

Point your client at it

Swap the base URL to http://localhost:8787/v1. Every OpenAI SDK, LangChain, LibreChat, Cursor, Continue and Cline already understand it.

02

Ask for an alias, not a model

free, fast, smart, code, vision, long, reasoning — or a concrete provider/model.

03

Ship, and stop reading rate limits

The router keeps trying alternatives, honours cool-downs and reports which provider answered in the router field and the x-router-provider header.

# clone, add one key, run
$ git clone https://github.com/djsTimhac/FreeUnlimitedAIRouter.git
$ cd FreeUnlimitedAIRouter
$ cp .env.example .env   # paste a free Groq or Gemini key
$ npm start
